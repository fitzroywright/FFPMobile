# Common.Security login integration

[Warehouse Phase 1](WAREHOUSE-PHASE-1.md) describes the .NET 11 API, the Common.Security Active Directory provider, approved identity bindings, device enrollment, session behavior and the FFP Manager permission commissioning requirements.

The Field Officers and Security Post apps are outside the Warehouse rollout. Their sign-in is not enabled by the Phase 1 API.

The native Kotlin apps currently provide UI previews. Their sign-in and Warehouse tablet enrollment still need to be wired to this API.
